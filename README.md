# БасТур — экскурсионные туры по Беларуси

Отдельный адаптивный сайт, Next.js + TypeScript + CSS. Node.js >=20.9.

## Запуск

Рабочая папка: `/workspace/site_1`.

```sh
npm ci --cache /tmp/npm-cache
npm run dev -- --hostname 0.0.0.0
```

Проверки: `npm run lint`, `npm run build`. Запуск production после сборки: `npm start -- --hostname 0.0.0.0`.

Сайт содержит 3 предложения из официального каталога на 20.10.2026. Цены не синхронизируются автоматически. Программы открываются в действующем каталоге агентства, связь — по подтверждённому телефону. Формы с имитацией отправки нет. Фотоматериалы предоставлены через официальную страницу заказчика; обложка «Мир и Несвиж» — композиция из каталога, не документальный кадр двух замков в одном месте.

## Перед публикацией

Задайте `SITE_URL` равным публичному адресу нового сайта (пример имён переменных в `.env.example`). Он используется для canonical и sitemap. Без него sitemap пуст, абсолютные URL намеренно не выдуманы. Подтвердите цены, разрешение на использование изображений, условия поездок. Даты и наличие мест не публикуются без подтверждения.

Публикация здесь не выполнялась. При размещении на Vercel укажите Root Directory по умолчанию (корень репозитория); для действующего коммерческого бизнеса выберите подходящий коммерческий тариф либо другой хостинг.

## Заявки в Telegram

Форма: `app/components/LeadForm.tsx`, сервер: `app/api/lead/route.ts`, проверка и доставка: `lib/lead.ts`. Заявки отправляются непосредственно боту, отдельной базы нет. Успех возвращается только при подтверждённом `message_id` от Telegram.

1. Добавить секрет `TELEGRAM_BOT_TOKEN` на сервере (не NEXT_PUBLIC).
2. Нажать «Старт» у бота; для группы добавить его туда и написать сообщение.
3. `NODE_USE_ENV_PROXY=1 npm run telegram:chat-id` — вывести ID доступных чатов. В облаке нужен Node.js 24+ для системного прокси; локально без прокси достаточно `npm run telegram:chat-id`. Команда не печатает токен и не отправляет сообщений.
4. Добавить `TELEGRAM_CHAT_ID` выбранного получателя.
5. До включения утвердить `/privacy`: сейчас это черновик с недостающими реквизитами/сроками/условиями обработки. Затем задать `LEADS_ENABLED=true` и перезапустить сервер.
6. Выполнить реальную тестовую отправку и проверить сообщение у получателя. Без этого доставка не считается проверенной.

Секреты из настроек этой среды не переносятся автоматически на хостинг. При публикации указать их заново в серверных настройках хостинга. Не передавать токены в чат, URL браузера или репозиторий.

Проверки: `npm run test:leads` (9 тестов с имитацией ответа Telegram), `npm run lint`, `npm run build`. Реальный Telegram тест требует настроенного бота и чата. Ограничение отправок действует в памяти одного процесса; на распределённом хостинге для общего лимита потребуется внешнее хранилище/защита платформы.

Скачанный `bastur.html` — прежняя статическая версия для просмотра; серверную отправку Telegram из отдельного HTML-файла использовать нельзя.
